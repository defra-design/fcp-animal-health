How the filters work -------------------- A GET form with an "Apply filters" button, as GOV.UK guidance advises. "Me" is the signed-in user, Sanjay Mehta. "Case officers" and "Team leads" use each person's role when they created the flag. Sorting ------- The table uses the MOJ Design System sortable table (MOJ Frontend is already installed and loaded by the kit): select a column heading to sort by it. Only some columns sort, where the order helps: type, why, flagged by and date. GOV.UK Frontend has no sortable table, but the MOJ one is an established cross-government pattern for case-working tools, built on GOV.UK Frontend, with accessible sort buttons. It sorts the rows on the page only. A live service with pagination would sort on the server, across every result. Sorting uses data-sort-value where the cell text would sort wrongly, for example dates. Data ---- Flags are in app/views/prototypes/back-office/data/flags.js, with flags added and removed in the prototype applied by app/views/prototypes/back-office/routes.js.
